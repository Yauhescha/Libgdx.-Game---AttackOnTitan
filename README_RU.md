# Titan Hook Runner — исходники 2.2, 28 сентября 2026

Доработанный Java/libGDX-проект для Android. В этой версии восстановлено подключение оригинальных
анимаций и звуков, добавлена картинка газа и переработан выбор персонажей.

## Добавление персонажей без изменения Java

1. Создать папку `assets/player/<имя_папки>/` с `stand.png` и кадрами в `attack/`, `dead/`; при
   наличии — `attackEffect/` и `sound/`.
2. Добавить запись в массив `characters` в **`assets/config/characters.json`**: ID, название, папка,
   цена, сила якоря, скорость и радиус атаки.
3. Кадры PNG и звуки подхватываются автоматически. Порядок карточек соответствует JSON; для
   количества больше пяти есть страницы.

Готовая запись для копирования: `docs/character-example.json`.
Полная инструкция и необязательные настройки: **`docs/ADDING_CHARACTERS_RU.md`**.
Исходные пять персонажей уже переведены на этот конфиг; их ID и покупки сохранены.
Для Android изменения ассетов попадают в приложение после пересборки APK пользователем; в Java
ничего дописывать не нужно.

## Что изменено

- Оригинальные анимации атаки всех пяти персонажей и общий эффект клинков подключены к
  автоматическому удару по затылку. Анимация разворачивается по направлению движения.
- После убийства титан проигрывает все 14 кадров оригинального испарения. Мёртвый титан больше не
  наносит урон и не приносит повторные награды.
- Дым полёта использует исходные четыре кадра; след остаётся в пространстве и затухает. Его скорость
  не зависит от FPS.
- Восстановлены анимации смерти игрока, оригинальный звук удара и случайные звуки смерти Эрена,
  Армина и Бертольда. В исходных ассетах нет голосов Энни и Микасы: они временно используют звуки
  Армина. Общий звук атаки сохранён для всех.
- Экран поражения появляется после анимации смерти. Испарение титанов продолжает проигрываться после
  окончания забега.
- Газ постоянно расходуется, при натянутом якоре — быстрее. Подбор баллона полностью восстанавливает
  запас. Баллоны плавно опускаются; если газ закончился, следующая поставка появляется по
  горизонтали рядом с игроком.
- Якорь тянет к пальцу по обеим осям. Для удара нужно облететь титана и зайти к затылку сверху;
  титаны движутся вниз. Подсветка зоны затылка показывается только в тренировке.
- Пауза останавливает движение, эффекты и расход газа; при сворачивании незавершённый забег ставится
  на паузу.
- В магазине нажатие на карточку открывает предпросмотр с анимацией и характеристиками. Покупка /
  выбор выполняются отдельной кнопкой.
- Сохранены главное меню, режимы Training / Expedition / Survival / Combo, монеты и перенос старых
  разблокировок.
- Исправлены продолжение отрисовки уничтоженного экрана после перехода и освобождение ресурсов
  текущего экрана при закрытии приложения.

## Как заменить мок-картинку газа

Заменить **`assets/pickups/gas-canister.png`** своим PNG с прозрачностью и тем же именем. Код менять
не нужно. Подойдёт квадратный холст, например 256 × 256; баллон располагается по центру. На уровне
изображение отображается в области 70 × 70 игровых единиц. Радиус подбора задаётся независимо в
`GasPickupState`.

Исходные кадры и звуки не заменялись:

- `assets/player/<персонаж>/attack/` — атаки;
- `assets/player/<персонаж>/dead/` — смерть персонажа;
- `assets/player/eren/attackEffect/` — эффект клинков;
- `assets/effect/flying/` — дым полёта;
- `assets/effect/dissapearing/` — испарение титанов (историческое написание папки сохранено);
- `assets/player/sound/attack.wav` и `assets/player/<персонаж>/sound/` — звук.

Временный PNG создан встроенным генератором изображений. Запрос: простой бирюзовый баллон газа для
2D-игры, серый вентиль, белая надпись GAS, тёмный контур, прозрачный фон, минимум деталей.

## Сборка на Windows

1. Нужны JDK 17 и Android SDK 35 с Build Tools. Путь к SDK задаётся Android Studio в
   `local.properties` либо переменной `ANDROID_HOME`.
2. Распаковать архив и открыть папку `AOT_Final_Sources`.
3. Запустить `build-windows.bat`. Он скачивает закреплённый Gradle 8.11.1 в `.gradle-dist` и
   запускает только `:android:assembleDebug`.
4. Результат: `android/build/outputs/apk/debug/android-debug.apk`.

Для Android Studio используйте JDK 17 для Gradle; если IDE спрашивает дистрибутив Gradle, укажите
`.gradle-dist/gradle-8.11.1` после запуска скрипта. Gradle Wrapper в проект не включён.

## Android и 16 KB

В конфигурации оставлены AGP 8.9.3, libGDX 1.14.2, compile/target SDK 35 и
`useLegacyPackaging=false`. Нативные библиотеки берутся из зависимостей libGDX для `armeabi-v7a` и
`arm64-v8a`, а не из старого архива. Runtime FreeType отсутствует: шрифт уже находится в
`ui-font.fnt` / `ui-font.png`. x86_64 в эту мобильную сборку не включён.

Это настройки проекта для современной упаковки нативных библиотек; совместимость конкретного APK с
устройством на 16 KB в этом проходе не подтверждалась. Тесты, сборка и дополнительные проверки APK
по просьбе пользователя не запускались. Готовый APK в архив не включён.

Документация Android: https://developer.android.com/guide/practices/page-sizes
Версия libGDX: https://libgdx.com/news/2026/05/gdx-1-14-1

## Прогресс

Сохранён `applicationId` `com.hescha.game`. Для установки поверх прежнего приложения с сохранением
данных нужна та же подпись. Удаление старого приложения удаляет и его локальные сохранения. Перенос
монет и разблокировок из `AOTGame-2023-17-10` выполняется один раз.
